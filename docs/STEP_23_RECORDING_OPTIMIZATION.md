2026-11-01. 검사 빈도를 줄이지 않고 반복 JSON 변환을 제거했다.

짧은 3초 시뮬레이션 구간을 프로파일링했더니, 전체 관측 기록을 켠 경우 물리 계산보다 `json_safe`를 반복 호출하는 시간이 컸다. 기록 없는 구간과 기록을 켠 구간을 따로 측정해 원인을 확인했다.
