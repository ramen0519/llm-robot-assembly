# 22Q · 슬리브 경험을 검색한 뒤 첫 파지 결정하기

**2026-11-11. 슬리브2·4의 첫 파지 사전검사에서 패드–작업대 접촉이 2/2건에서 0/2건으로 줄었다.** 두 부품 모두 검색 후 처음 제안한 좌표로 집기부터 삽입과 해제까지 통과했다.

## 소스 경험

22P의 실제 두 에이전트 회차 `20261111T094837_356839Z_dfd0a272`에서 슬리브1의 파지를 추출했다. 중심보다 5 mm 낮게 잡으려는 첫 후보는 손을 닫는 단계(`pick_close`)에서 오른쪽 패드와 작업대가 접촉해 무조코 사전검사에서 거절됐다. 복구 에이전트가 제안한 +12 mm 파지는 사전검사를 통과했고, 원래 장면에서 양쪽 패드 접촉과 지지 해제, 99.56 mm 들어 올림 및 최종 삽입이 확인됐다.

저장된 카드에는 파지 XYZ와 회전각, 접촉 쌍·실패 단계, 수정, 원래 장면의 검증 근거, 적용할 수 있는 슬리브 형상·축·단위·장비 조건이 들어 있다. 근거 파일의 지문과 모델 응답 ID는 저장된 레코드에 남는다. 검색 대상에는 슬리브2·4의 과거 제안이나 복구 결과를 넣지 않았다. 카드 ID는 `719902ec44642017e2d48067db7d3f3a05f5a183736331aa3096d7dbc7302633`이다. [경험 저장·조회 모듈](../scripts/sleeve_grasp_memory.py)

## 비교 방법

각 대상의 22P 작업 시작 시점으로 돌아가 로봇·그리퍼·작업대 위의 모든 부품 상태를 복원한다. 슬리브2와 슬리브4의 작업 시점은 서로 다르다. 각 슬리브 안에서 동일한 출발 상태를 두 번 사용한다.

- **기억 없이 정한 기존 첫 후보**는 22P 조립 에이전트가 실제로 제안했던 값이다. 이 후보가 같은 상태에서 동일한 접촉을 일으키는지 새 무조코 검사로 확인한다.
- **기억을 검색한 새 첫 후보**는 동일한 형상과 관측을 받은 Astra high 조립 에이전트가 정한다. 에이전트가 검색어를 제안하면 호스트가 현재 부품과 호환되는 경험을 찾고, 에이전트는 반환된 카드를 보고 좌표와 회전각을 결정한다. 카드의 수치를 강제로 적용하지 않는다. [조립 전 검색 도구](../scripts/sleeve_memory_policy.py)
- 주 측정값은 첫 후보가 `pick_close`에서 그리퍼 패드–작업대 접촉으로 거절된 횟수다. 다른 단계에서 실패하거나 모델이 보류한 경우도 별도로 남긴다. 전체 사전검사 통과 여부도 확인한다. 이 시험의 검사 사본은 집기·운반·삽입·해제까지 실행한다. 원래 장면의 9부품 연속 조립은 22P 보고서에 있다. [22P 실행 근거](STEP_22P_ASSEMBLY_RECOVERY_AGENTS.md)

## 실제 결과

| 대상 | 22P에서 기억 없이 정한 첫 파지 Z | 기억 검색 후 새 첫 파지 Z | 패드–작업대 접촉 | 전체 사전검사 |
|---|---:|---:|---|---|
| 슬리브2 | −7 mm | +12 mm | 발생 → 없음 | 거절 → 통과 |
| 슬리브4 | −5 mm | +12 mm | 발생 → 없음 | 거절 → 통과 |

두 제안 모두 부품 중심 기준 X=Y=0 mm, 손가락 회전각 0°였다. Astra는 각 대상에서 독립적으로 검색어를 작성했고 두 번 모두 슬리브1 카드가 반환됐다. 두 응답 모두 선택 이유로 슬리브1의 낮은 파지와 작업대 접촉, 수정 후 성공을 언급했다. 슬리브4 응답은 현재 슬리브의 치수(36×36×30 mm), 구멍 폭(24 mm), 기둥 폭(20 mm)도 대조했다.

각 검사 사본에서 손을 놓은 뒤 목표 위치·자세, 지지, 안정성, 기둥의 양쪽 구멍 관통을 확인했다. 다른 종류의 거절 및 보류는 두 조건 모두 0건이었다. 실제 모델 호출은 검색 2회와 첫 파지 결정 2회다. 총 입력 7,413토큰, 출력 906토큰(그중 추론 520), 응답 사용량에 설정 단가를 적용한 추정 비용 **$0.134895**, 실험 상한 **$0.40**. 대조군은 저장된 모델 결정을 사용해 추가 모델 비용이 없었다.

이번 결과는 이전에 접촉을 보였던 같은 형상의 두 개발 사례에 대한 첫 후보 비교다. 목표별 최초 관측과 이전 모델의 무기억 입력이 일치했고, 두 조건의 복원 상태 지문도 같았다. 무기억 모델을 새로 여러 번 표집하거나 새로운 제품을 평가한 시험은 후속 범위다.

새 자동 검사 9개가 통과했다. 부품·장비·상태 조건이 다른 경험의 제외, 원본과 저장 내용의 불일치 검출, 검색과 파지 결정의 순서 및 공통 예산, 첫 검사 후 본 장면의 집기 차단, 보류와 다른 원인 실패의 별도 집계를 확인했다. 기존 역할 인계·모델 호출·조립 경로의 관련 회귀 검사도 통과했다.
