# 31. 분해 추천 순서를 이용한 독립 조립

분해 프로그램이 알려주는 것은 각 부품의 CAD와 완성 위치, 조립을 시도해 볼 순서다. 조립기는 자기 작업대에서 어느 부품을 집을지, 어떻게 옮길지, 놓은 뒤 제 위치를 유지하는지 확인한다.

## 입력

`assembly_order_hint/v1` 목록의 제품별 `assembly_hint.json`이 입력이다. CAD 목록과 부품별 파일의 SHA-256, 단위, 부품 좌표계와 조립 좌표계를 대조한다. 첫 번째 추천 부품을 작업대에 고정할 받침으로 사용하고 나머지를 조립 후보로 읽는다. 기존 분해 검증과 제거 궤적이 필요한 경우에는 `disassembly_export/v1`을 계속 사용할 수 있다.

아래는 준비만 하는 명령이다. `$out`에는 새 폴더 경로를 쓴다.

```powershell
cd C:\dev\llm-robot-assembly
$py = '.\runtime\luna-venv\Scripts\python.exe'
$hint = 'F:\dev\llm-robot-assembly-data\inputs\asap_training_complete_20261125_01\products\04688\assembly_hint.json'
$out = 'F:\dev\llm-robot-assembly-data\runs\my_new_04688_preparation'
& $py -B scripts\run_assembly.py prepare --input $hint --output $out --seconds 480
```

`prepared_geometry`는 충돌 형상과 작업대 배치가 준비됐다는 뜻이다. 이어지는 `run`에서 조립기는 모든 부품을 완성 위치에 놓은 별도 장면을 만들고 중력을 켜서 목표 자체가 유지되는지 본다. 통과하면 준비된 부품을 공급 위치에 놓고 UR3e·2F-85 한 대로 파지와 이동을 시작한다. 분해 때 사용한 지지 수와 이동 경로는 이 과정의 입력에 들어가지 않는다.

## 조립 중 순서와 기억

Astra는 손이 비어 있고 장면이 안정적이며 주 장면에서 아직 해당 부품을 움직이기 전에 다른 추천 부품을 먼저 검토할 수 있다. 미룬 부품은 다른 부품을 실제로 설치한 뒤 다시 시도할 수 있다. 잡은 뒤의 실패는 조립 실행기의 복구 절차로 처리한다. 주 장면을 되감아 결과를 만들지 않는다.

`--policy astra --condition R0 --split collection`은 조립 학습 설정이다. 이전 조립 기억 조회를 끄고 새 복구 경험을 기록한다. 원래 목표의 실제 복구와 종료 시 보존, 근거가 연결된 지침, 재생 가능한 증거를 갖춘 경우에만 새 사례를 등록한다. 제품별 실제 명령과 토큰·비용은 이번 연구 기록에 저장했다.

## 확인한 범위

조립 v2 자동 검사 32개가 통과했다. 추천 순서 입력 경로에서 별도 분해 호출 없이 실제 CAD의 단위·목표 자세를 읽었고, 세 부품의 작은 MuJoCo 장면에서는 첫 부품을 미루고 다음 부품을 검토하는 동작을 확인했다. 이 작은 검사는 미리 작성한 정책으로 했다.

301개 원본 부품을 포함한 16종을 전달했다. 24부품 04688에서는 모든 충돌 형상이 준비됐지만 고정 받침 8번 위에 있던 0번이 시뮬레이션 0.028초에 3.91mm 내려가 예상하지 않은 접촉이 관측됐다. 조립기가 모델 호출 전에 중단했다. 수치가 달라지도록 CAD나 지지 조건을 조정하지 않았다. 아주 작은 삼각형과 불필요한 직교 격자 분할을 처리하는 입력 보완은 기존 표면 거리·부피·구멍 검사와 함께 적용했다.

20부품 01657은 10번과 7번이 0.032초에 각각 5.22mm, 5.16mm 내려가 위치 허용치를 넘었다. 16부품 06534는 0.020초에 15번이 3.97° 돌아 자세 허용치를 넘었다. 세 회차 모두 목표 장면에서 종료됐다. 모델 호출 0회, 추정 비용 $0, 설치 0개, 새 기억 0건이다.

06534는 원래 단면이 일정한 19번 부품을 10개 볼록 조각으로 표현했다. 임의 방향의 양쪽 단면과 평행한 옆면을 확인하고 원래 CAD의 단위 변환 정밀도와 빈 공간을 보존했다. 원본 대비 부피 차이는 약 0.00018%였다. 곡면을 단순한 껍질로 막거나 조립의 접촉·자세 허용치를 바꾸지 않았다.

전체 제품별 상태와 새 조립 경험 건수는 F 연구 폴더의 `evidence/assembly_v2_training_handoff_20261125_01/ASSEMBLY_RESULTS.json`에서 확인할 수 있다.
