# 18단계 — 첫 기둥의 물리 삽입

2026-11-01. **받침대 + 기둥 1개 조립 성공.** 10부품 전체 조립, LLM 계획, 실패 복구는 아직 아니다.

## 동작을 쉽게 설명하면

1. 기둥이 작업대에 안정적으로 놓였는지 읽는다.
2. 손가락으로 기둥을 잡고, 양쪽 접촉을 확인한 뒤 들어 올린다.
3. 현재 손과 기둥의 상대 위치를 측정한다. 이를 이용해 기둥이 구멍에 들어갈 때 필요한 TCP 목표를 계산한다.
4. 구멍 위로 이동하고 수직으로 내린다. 목표 자세는 Mink IK로 계산하며, 중간 경로의 충돌을 먼저 검사한다.
5. 기둥이 충분히 들어온 것을 측정하고 손가락을 연다.
6. 손을 위로 빼고, 기둥이 구멍 바닥에 지지된 채 멈춰 있는지 확인한다.

`insert_post/v1`은 실행 코드로 만든 기본 스킬이다. LLM이 나중에 이 스킬을 선택할 수 있지만, 지금 단계에서는 고정된 순서로 실행한다.

## 성공 기준

마지막 안정 구간에서 모두 만족해야 한다.

- 기둥과 구멍 바닥 사이에 실제 지지 힘이 있음.
- 양쪽 손가락 접촉 없음, 그리퍼 간격 80 mm 초과.
- 기둥 목표 위치 오차 1 mm 미만, 방향 오차 1도 미만.
- 삽입 깊이가 명목 16 mm에서 1 mm 이내.
- 기둥 선속도 1 mm/s 미만, 각속도 0.01 rad/s 미만.
- 접촉 침투량 1 mm 미만.

TCP가 도착했다는 이유만으로 조립 성공으로 판단하지 않는다. 작업대에 놓인 기둥은 구멍 바닥의 지지를 만족하지 않으므로 실패다.

삽입 구간에는 선택한 기둥과 받침대의 접촉만 허용한다. 로봇/그리퍼와 받침대의 충돌은 계속 거부한다. 기둥-받침대 한 접촉점의 수직 접촉력 8 N 초과도 중단한다. 이는 개발용 시뮬레이션 검사값이며 실물의 안전 한계로 사용하지 않는다.

## 코드와 기록

- `scripts/insertion_skills.py`: 삽입 동작, 접촉 정책, 독립 조립 검사.
- `scripts/run_insertion.py`: 실행·CSV·결과·FailureReport·이미지.
- `scripts/workcell_verification.py`: 접촉 허용 정책을 확장 가능하게 분리. 기존 집기/놓기 정책은 유지.
- `scripts/run_pick_place.py`: 실패 기록에 사용 스킬과 검사 프로필을 전달할 수 있도록 확장.
- `tests/test_insertion.py`: 실제 조립, live qpos/qvel 강제 변경 금지, 접촉 허용 범위, 작업대 놓기를 성공으로 오인하지 않음, 파지 실패 기록과 중단.

실행 중 로봇이나 기둥을 순간이동시키거나 weld로 붙이지 않는다. IK 계산용 복사 상태에서 운반 자세를 예측하는 것과 실제 물리 상태는 구분한다. headless 실행과 생성 이미지는 확인했으며, 이번 단계의 대화형 창은 별도로 열어 검사하지 않았다.
