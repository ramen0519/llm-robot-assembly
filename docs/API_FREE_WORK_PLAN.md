# API 없는 준비 작업 — 2026-11-01

사용자 요청에 따라 집에서 키를 준비하기 전에 현재 제품의 시뮬레이션·외부 계획 연결·실행 준비를 진행했다. 아래에 정한 준비 범위는 완료했다. 실제 모델 판단, 실물, 임의 제품 일반화까지 완료했다는 의미는 아니다.

| 25C 변경 조건 시험 | 사전 선언한 배치·장애물의 8회 물리 시험. 조립 성공 6회·의도한 중단 2회 | 완료 · [25C](STEP_25C_CHANGED_CONDITIONS.md) |

실제 프로젝트 LLM API 호출과 실물 명령은 0회다. `single/roles`는 규칙 정책 시험이며 가짜 HTTP 응답의 토큰 수를 모델 성능으로 쓰지 않는다. 외부 플래너 원본 프로젝트와 과거 결과는 변경하지 않았다.

이후 키가 있어야 검증할 항목은 실제 모델의 도구 선택·오류·토큰·비용, 단일/다중 모델 성능과 경험·스킬 활용 효과다. 현재 live 연결은 첫 결합의 단일 정책이며 전체 프레임과 실제 다중 LLM은 작은 시험 통과 후 확장한다.

키 없이도 추가 가능한 연구 범위는 새로 얻은 외부 10부품 순서의 전체 로봇 실행, 파지·접근 대안, 더 다양한 실패·제품·별도 평가셋이다. 이번에 끝낸 준비 범위와 구분한다. 기존 전체 조립 성공은 개발자가 정한 순서이며 외부 10부품 후보의 성공으로 대신 세지 않는다. 전체 장기 실행 도중 일부 모듈이 갱신된 점과 최종 코드의 별도 검사 범위는 23I에 기록했다.
