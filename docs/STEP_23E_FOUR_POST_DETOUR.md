# 23E: 네 기둥 연속 조립에서 우회와 기존 조립물 보존 검증

작성: 2026-11-01. [23D](STEP_23D_RETAINED_PART_DETOUR.md)의 코드를 변경하지 않고 바닥판과 네 기둥까지 실제 MuJoCo 실행을 확장했다. 실행 소스는 `98e8536`이다.

## 이번 단위의 의미

기둥을 하나 설치할 때마다 다음 작업 주변에 조립물이 늘어난다. 네 번째 기둥을 설치할 때는 앞선 세 기둥도 계속 제 위치에 지지된 채 있어야 한다. 같은 모델과 물리 상태를 유지하면서 모든 부품의 접촉·위치·방향·속도를 검사했다. 중간 상태 초기화, 부품 순간이동, 인공 부착 없이 실제 그리퍼 접촉으로 네 기둥을 설치했다.

성공 기준은 로봇 설치 4/4, 각 기둥 해제·후퇴 후 결합 검사 통과, 마지막 시점에서 전체 조립물의 상태 검사 통과다. 바닥판은 처음부터 고정한 부품이다. 따라서 제품 5부품의 개발 시험이며 전체 10부품 완료로 집계하지 않는다.

## 검증 범위와 다음 단계

이번 변경은 실행 근거와 문서뿐이다. 23D에서 통과한 코드 검사 전체를 반복하지 않고, 새 조건인 네 기둥 연속 물리 실행을 수행했다. 고정 장면·seed 3의 개발 검증 한 번이며 일반적인 성공률이나 LLM 판단 효과 실험이 아니다.

다음은 슬리브와 덮개의 복합 충돌 형상, 파지 유지, 기존 조립물 보존을 별도 운반 시험으로 확인하는 것이다. 개별 부품 시험에서 미리 조립한 자유 물체는 초기 시험 준비물로 기록하며 로봇 설치 수에 포함하지 않는다. 실물 작업은 제외한다.
