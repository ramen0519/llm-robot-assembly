## 성공 판정

- 빈 바닥판과 자유 부품 9개에서 시작한다. 첫 기둥만 개발용 파지 높이 +1 mm를 주고, 무조코가 손가락 패드와 소켓 벽의 간섭을 측정해야 검색에 들어간다. Astra가 직접 검색하고 문서를 읽고 선택한 스킬이 현재 관측으로 계산한 새 파지를 재검사한다.
- 같은 장면에서 각 부품의 승인 파지와 실행 파지가 일치해야 한다. 이전 부품 설치 종료와 다음 부품 시작의 전체 물리 상태와 설치 목록을 대조한다. 마지막에는 기둥·슬리브 위치, 네 슬리브의 관통, 덮개 구멍 네 개의 관통, 네 슬리브 각각의 수직 지지력을 검사한다.
- 시뮬레이션에서 확인한 조립 순서와 모델 결정 기록을 외부 계획의 채택 기록에 연결했다. 이 구성은 알려진 프레임 한 개를 대상으로 한다.

## 실제 결정과 측정 결과

첫 기둥에서 예상 패드–벽 여유가 −2.37 mm로 측정됐다. Astra가 `post insert_lower preflight pad socket wall grasp`를 검색하고 실패 경험과 스킬 문서를 읽은 뒤 검증된 스킬을 선택했다. 그 코드가 +4.37 mm 파지를 계산했고, 현재 장면 사본 재검사를 통과한 값으로 원래 장면에서 설치했다. 슬리브3의 첫 제안(−7 mm)은 오른쪽 패드가 작업대와 접촉해 집기 사전검사에서 거절됐다. 이번에는 Astra가 접촉 보고서를 보고 파지를 직접 +10 mm로 고쳐 설치했다.

- **완성 상태.** 덮개 장착 후 9개 부품의 최종 목표 위치 오차 최댓값은 **0.227 mm**였다. 기둥과 슬리브 구멍 사이의 최소 측면 여유는 **1.791 mm**, 기둥과 덮개 구멍 사이의 최소 측면 여유는 **1.823 mm**였다. 덮개가 슬리브 1~4에 전달한 수직 하중은 각각 **0.209, 0.181, 0.207, 0.196 N**이었다.
- **연속성.** 한 프로세스에서 바닥판만 고정한 상태로 시작했다. 8번의 부품 전환 모두 직전 종료 시점과 다음 시작 시점의 전체 상태 배열·시각·설치 목록이 일치했다. 526,251개 물리 기록에서 각 부품의 그리퍼 닫기·들기·삽입·해제·후퇴를 확인했다. 최종 상태를 따로 복원해 네 슬리브의 관통과 덮개의 관통·지지를 다시 측정했고 원래 측정값과 일치했다.
- **모델과 비용.** Astra high 생성 **21회** 중 검색·열람·선택 3회, 일반 파지 제안 9회(슬리브3 수정 포함), 삽입 결정 9회였다. 입력 45,334토큰, 출력 9,818토큰(추론 포함 7,645토큰). 설정 단가 기준 추정 **$0.997987**, 승인 상한 $1.50, 미정산 요청 0회. 시뮬레이션 경과 **1,052.142초**, 실행기에서 측정한 실제 경과 **약 68분**이다.
- **회귀 검사.** 외부 순서가 라이브 모델의 요청에 전달되고 잘못된 부품 제안이 움직임 전에 거부되는 사례, 후보·장면 불일치의 호출 전 거부, 기존 조립·재개·복구 동작을 포함해 **24개** 검사가 통과했다.
- 실행 폴더에서 `native_assembly_stages.png`는 첫 기둥·덮개 직전·완성 시점, `native_plan_audit.txt`는 독립 재측정, `graph_events.jsonl`과 `result.json`은 원래 회차의 노드 결정과 물리 결과다. 한 개발 제품의 검증 회차이므로 새 조립품 성능과 반복 성공률은 별도 실험 대상으로 남는다.
