## 구현·기록의 제한

- 전체 새 제품 입력부터 12개 설치 완료까지의 성공은 확인하지 못했다. 단일 부품 후속 시험을 전체 성공으로 대체하지 않는다.
- 공구는 2F-85 본체에 총 길이 100mm, 폭 8mm, 끝 접촉부 4mm인 실험용 강체 손가락이다. 실물 제작·휨·허용 하중 검증은 없다.
- CAD 위치에서의 지지와 안정성을 검사한다. 전기 연결·용접·나사 체결·실제 배터리 취급을 구현한 결과가 아니다.
- 후속 시험은 검색을 사용하지 않았다. attempt03/04의 condition 문자열 R1은 메타데이터 오류이며 실제 동작은 조립/복구 역할, 검색 OFF다. attempt05부터 R0로 수정했다. 이 후속 시험들은 연구 비교군 데이터로 사용하지 않는다.
- attempt03은 안정성 검사 인수 누락으로 API 호출 전에 종료됐다. 수정 후 실제 501회 검사를 통과했다.
- attempt04의 후보 수 변경 시 공통 설정 해시 갱신이 누락됐다. 물리 모델·CAD 목표는 동일했으나 재실행 입력 계약으로 인정하지 않는다. attempt05는 새 설정 파일·해시와 변경 범위 검사를 적용했다. 원래 기록은 변경하지 않았다.
- 반복적인 입력 기하 재검증은 별도 60초 진단 제한에 걸렸다. 기록된 동일 MJB를 쓰는 후속 검사는 CAD/물리/배치가 그대로인지 확인하고 검색 한도·빈 공구 측정표 변경만 허용한다. 새 제품의 일반 입력 검사는 그대로 수행한다.
- 현재 회귀 검사 77개 통과. 기록 검사 통과는 물리적 조립 성공을 의미하지 않는다. 유효한 해결 지침·스킬을 새로 등록했다고 주장하지 않는다.
