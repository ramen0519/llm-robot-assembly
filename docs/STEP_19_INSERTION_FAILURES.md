# 19단계 — 측정으로 구분하는 실패

2026-11-01. 첫 기둥 결합에 대해 정렬·깊이·접촉력 검출기를 추가했다. 파지 실패/부품 놓침은 기존 검출기를 함께 사용한다.

| 코드 | 실제로 읽는 것 | 중단 시점 |
|---|---|---|
| GRASP_NOT_CONFIRMED | 양쪽 손가락 접촉·들어 올린 높이 | 집기 |
| PART_LOST | 접촉 소실·손과 부품의 상대 자세 변화 | 운반 중 |
| ALIGNMENT_OUT_OF_TOLERANCE | 구멍에 대한 XY 오차, 방향, 구멍 입구 위 여유 높이 | 삽입 하강 전 |
| INSERTION_DEPTH_NOT_REACHED | 부품 바닥으로 계산한 삽입 깊이 | 손을 놓기 전 |
| INSERTION_CONTACT_LIMIT | MuJoCo가 계산한 기둥-받침대 접촉점 법선 힘 | 매 물리 표본 |
| PLACEMENT_NOT_CONFIRMED | 손을 뗀 뒤 지지·자세·깊이·안정 상태 | 최종 판정 |

법선 힘은 접촉면에 수직인 힘이다. 접촉점당 8 N 기준은 임시 시뮬레이션 기준이다. 실제 로봇 안전값이나 전체 힘의 합계라고 해석하지 않는다.

정렬 확인 기준은 XY 1 mm 미만, 방향 1도 미만, 입구 위 5 mm 이상이다. 깊이가 부족하면 그리퍼를 열지 않는다. 실패 원인 가설을 LLM이 말하는 것과 이 측정 사실은 구분한다.

## 확인한 실패

```powershell
cd C:\dev\llm-robot-assembly
uv run --locked python scripts/run_insertion.py --headless --scenario alignment_offset
uv run --locked python -m unittest discover -s tests -p test_insertion_failures.py -v
```

첫 명령은 실패 재현 명령이므로 종료 코드 1이 정상 기대값이다. 기둥을 순간이동시키지 않고 실제로 6 mm 옆으로 운반한다. 정렬 검사에서 실제 오차 6.0753 mm를 읽고, 기둥을 잡은 상태에서 하강 전에 중단했다.

보고서: `runs/step18/20261101T043637_317870Z_01380fe9/failure_report.json`. 시뮬레이션 49.710초, phase `insert_alignment_check`. 목표·실제 로봇/부품 상태·접촉·오차·시점이 남는다. 과거 실행 명령과 호환하기 위해 기본 저장 폴더 이름은 step18을 유지한다.

검사 2개 PASS:

- 실제 6 mm 오정렬 이동 → 하강 안 함 → 파지 유지. 같은 실제 관측으로 깊이 부족도 검출.
- 별도로 컴파일한 1 kg 시험 기둥과 단단한 접촉 조건에서 작은 낙하 충격 → 실제 접촉력이 한계를 넘으면 INSERTION_CONTACT_LIMIT.

두 번째는 독립 검출기 시험이다. 명목 40 g 기둥 조립의 성공률에 포함하지 않는다. 처음의 큰 낙하 시험에서는 침투량 3 mm 제한이 먼저 작동했다. 제한을 완화하지 않고 시험 질량/접촉 조건을 명시해 힘 검출기를 독립 검증했다.
