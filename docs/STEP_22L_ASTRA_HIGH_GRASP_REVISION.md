# 22L · Astra high로 첫 기둥의 삽입 간섭 복구

2026-11-11. MuJoCo 3.17.0의 10부품 개발 프레임, 처음 설치하는 기둥 `post_1`(20×20×60mm). 기존 Luna 후보가 중심보다 1mm 높게 잡아도 삽입 전에 오른쪽 패드와 바닥판 벽이 간섭했다. 이 두 시도의 실제 기록을 받아 Astra가 파지 계산 함수를 작성했다. **새 함수로 Z=4.37mm를 계산했고, 복사 장면의 사전검사와 원래 시뮬레이션 장면의 설치·해제·독립 검증을 모두 통과했다.**

## 관측을 어떻게 수정에 사용했나

| 값 | 기존 후보 | Astra 수정 후보 |
|---|---:|---:|
| 기둥 중심 기준 파지 높이 | +1.00mm | +4.37mm |
| X / Y / 닫힘 각도 | 0mm / 0mm / 0° | 0mm / 0mm / 0° |
| 집기 직후 계산한 명목 삽입 위치의 패드 여유 | −2.37mm | +1.00mm |
| 복사 장면의 집기 | 성공 | 성공 |
| 복사 장면의 삽입 | 하강 경로에서 패드–벽 간섭으로 거절 | 삽입·해제와 최종 검사 통과 |
| 원래 시뮬레이션 장면 | 거절 후 빈 상태 유지 | 첫 기둥 설치 확인 |

22K의 Z=0, +1mm 실패 증거에는 예상 여유가 각각 −3.37, −2.37mm로 남았다. 22L은 새 시뮬레이션에서 실제로 +1mm 거절을 재현한 뒤 그 시도의 관측과 실패를 묶어 함수에 제공한다. v2 입력은 기존 범위·자세·예산 정보에 **예상 패드 여유(mm), 패드–벽 간섭 여부, 복사 장면의 집기 완료 여부**를 추가한다. 값의 출처는 집은 기둥의 자세를 명목 착좌 위치로 투영한 복사 장면의 측정이다.

Astra 원문이 반환한 계산은 `new_z = z + margin - clearance`이다. 이 장면에서 `1 + 1 − (−2.37) = 4.37mm`다. 가운데 1mm는 Astra가 제안한 여유다. 이 기둥에서 확인한 값이며 다른 물체의 공차나 필수 여유로 확정하지 않는다. 실제 반환 원문의 해시는 재검사·실행의 저장 코드 해시와 일치했다. 원문을 제한 계산기에서 실행했을 때 현재 입력에서 네 파지값을 반환했고, 이미 파지 중·오래된 관측·여유 미측정·다른 접촉·남은 횟수 0의 다섯 통제 입력에서는 각각 보류를 반환했다.
