# 23C단계: 10부품을 같은 시뮬레이션에서 끝까지 조립하기

작성: 2026-11-01. 이번 단계의 완료 기준은 **처음부터 놓여 있는 부품 9개를 로봇이 차례로 집어 설치하고, 마지막에 전체 결합을 확인하는 것**이다.

## 무엇을 조립했나

제품은 바닥판 1개 + 기둥 4개 + 슬리브 4개 + 덮개 1개, 총 10부품이다. 슬리브는 기둥에 끼우는 속이 빈 사각 부품이다. 바닥판은 시작 전 고정돼 있으며, 로봇이 실제 설치하는 부품은 9개다. 트레이·작업대·그리퍼는 제품 개수에 포함하지 않는다.

개별 결합 시험과 달리 기둥이나 슬리브를 미리 조립한 상태에서 시작하지 않는다. 같은 MuJoCo 장면과 물리 시간을 유지하며 9번의 집기·운반·삽입·해제·후퇴를 수행했다. 실행 중 부품 위치 초기화나 강제 부착을 사용하지 않았다.

제품은 개발용 사각 프레임이며, 정밀 압입·나사 체결이나 기능성 기어박스는 아니다. 바닥판 폭 160mm, 기둥 폭 20mm, 구멍 폭 24mm로 한쪽 여유가 2mm인 설계다. 구조 정보·파지점·초기 위치·선행 조건은 우리가 작성했다.

## 첫 실패에서 복구한 뒤 나머지도 조립했나

첫 기둥의 정렬 목표를 6mm 틀리게 줬다. 측정한 정렬 오차가 허용치를 넘자 하강 전에 멈추고 FailureReport를 저장했다. LangGraph가 recovery 역할로 넘겨 현재 파지를 다시 확인한 뒤, 수직 후퇴·재정렬·삽입을 실행했다. 이후 assembly 역할로 돌아가 나머지 부품을 조립했다.

전체 작업에 복구 예산은 1회다. 부품마다 새 예산을 주지 않았다. 이번 역할별 판단은 **규칙 정책**이며 LLM/API 호출은 0회다. 분해 플래너가 이 제품의 순서를 생성한 시험도 아니다.

## 무엇을 검사했나

각 물리 단계에서 로봇·그리퍼·운반 부품·주변 부품의 금지 접촉과 파지 상태를 검사했다. 이미 조립된 부품과 아직 대기 중인 부품도 위치·방향·지지를 유지해야 한다. 삽입 중 실제 맞닿는 이전 부품의 작은 일시적 움직임과 최종 정지 조건을 구분한다. 구체적인 한계와 실패 사례는 [23B단계](STEP_23B_COMPOUND_COMPONENTS.md)에 기록했다.

각 삽입 완료는 해제, 위치 1mm 이내, 방향 1도 이내, 깊이 충족, 선속도 1mm/s 미만, 각속도 0.01rad/s 미만, 관통 1mm 이내, 선언한 결합면의 지지를 확인했다. LLM의 성공 선언이나 화면 캡처를 판정 근거로 사용하지 않는다.

## 실행과 파일

```powershell
cd C:\dev\llm-robot-assembly
uv run --locked python scripts/run_frame_assembly.py --parts 10 --mode roles --scenario first_alignment_offset --snapshots
# 같은 작업을 창에서 보려면 위 명령 끝에 --viewer 추가
# 먼저 작은 작업을 확인하려면 --parts 2 사용
```

근거 폴더: `runs/step23_frame/20261101T052809_562769Z_f77121fb`.

- `result.json`: 전체 결과·부품별 판정·그래프 최종 상태.
- `failure_001.json`: 첫 정렬 실패의 실제 관측. 최종 성공 뒤에도 삭제하지 않는다.
- `graph_events.jsonl`: 역할 인계·관측 revision·행동·종료 기록.
- `skill_trace.csv`: 실행 중 물리 관측.
- `resolved_config.json`: 장면과 실행 시작 시점의 핵심 파일 지문.
- `after_post_*.png`, `after_sleeve_*.png`, `after_cover.png`: 각 설치 후 화면.

이 긴 시험은 실행 시작 시점의 코드를 사용했다. 실행 도중 별도로 추가된 TCP→RRT 연결·viewer·절차 등록 기능까지 이 실행이 검증한 것은 아니다. 이 기능들은 각자 보고서의 별도 시험으로 확인했다. 원본 실행 파일은 Git에서 제외하고 보고서에 경로·수치·조건을 남긴다.

최종 화면을 직접 확인했다. CSV 전체 512,013행을 다시 읽어 관측 수가 결과 파일과 일치하고, 시뮬레이션 시간이 뒤로 가지 않으며, 기록 간격이 최대 0.002초임을 확인했다. 이는 추적 기록의 연속성 확인이며 새로운 물리 시험 1회로 추가 집계하지 않는다.

한 개발 조건의 전체 조립 1회 통과다. 새 배치·새 제품·다른 물성에서의 성공률이나 범용 조립 능력을 입증하지 않는다. 실제 LLM 판단, 이 제품에 대한 외부 분해 계획 생성, 전체 조립에 장애물 우회 자동 연결, 다양한 복구, 스킬·메모리의 성능 개선은 후속 작업이다. 실물은 이번 범위에서 제외했다.
