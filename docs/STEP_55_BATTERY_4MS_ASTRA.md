## 남은 문제와 다음 순서

1. API 없이 저장 실패 상태에서 실제 접촉한 연결부와 케이스 위치를 기준으로 파지 방향/파지 높이/해제 경로를 비교한다. 작은 파지값 변경이 실제 설치·해제 여유를 늘리는지 먼저 측정해야 한다.
2. 끝 자세에 도착하는 것과 손을 벌리고 빠져나오는 것을 구분해 해제 경로까지 통과한 후보를 찾는다. 현재 공통 검사에는 해제 검사가 있지만 이번 후보들은 통과하지 못했다.
3. 검증된 수정이 준비되면 남은 총 예산과 별도 시간 범위 안에서 Astra를 재실행한다. 12개 전체 조립·새 해결 경험 등록·다음 실행 재사용은 아직 남아 있다.

반복 후보 전달은 줄였지만 전체 공유 이력은 계속 증가하고 복구 요청의 캐시 쓰기 비용도 남아 있다. 시작 준비/기하 검사에 여러 분이 걸려 0.004초만으로 전체 실행이 두 배 빨라진다고 주장할 수 없다. 이 결과는 development 진단이며 collection/evaluation에는 사용하지 않는다.
